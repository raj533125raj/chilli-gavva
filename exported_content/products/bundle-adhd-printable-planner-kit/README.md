## How to use

1. Print the A4 or US Letter file at 100% (actual size).
2. Start each day with the Today page. On hard days, use the Low-Energy Reset Sheet instead.
3. When your head feels full, use the Brain Dump & Sort page, then move three things to the Daily Focus Sheet.
4. Plan the week with the Weekly Overview and look back with the Monthly Review.
