## How to use

1. Open the file in Excel or Google Sheets and enable editing.
2. Fill in the Overview tab to set project dates, budget, and status (calculated automatically).
3. Enter client details on the Client Info tab, then record the signed agreement on the Agreement tab.
4. Add required files on the Assets tab, list deliverables, and keep the Timeline, Payment, and Communication Log tabs updated weekly.
