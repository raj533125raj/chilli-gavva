## How to use

1. Duplicate the template into your own Notion workspace using the “Duplicate” button on the Gumroad download page.
2. Add new ideas to the Idea Bank, tag them, set priority, and optionally assign an estimated creation time.
3. Drag ideas into the Content Calendar, choose a publish date and platform, and set the post type.
4. For each published piece, open the Repurposing Checklist, add tasks for each new platform, set due dates, and tick off as you complete them.
5. Use the Dashboard’s weekly snapshot to see what’s due, what’s in progress, and what needs repurposing at a glance.
