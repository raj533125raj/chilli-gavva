## How to use

1. Open the file in Google Sheets (or import to Excel) and click **File → Make a copy** to own your version.
2. Add each piece of equipment to the **Gear List** tab, filling cost, purchase date, and replacement cycle.
3. Record each trip in the **Travel Log**, selecting the gear you took on that trip.
4. Check the **Summary Dashboard** to see upcoming replacement dates and total travel spend; export the dashboard as PDF if you need a printable report.
