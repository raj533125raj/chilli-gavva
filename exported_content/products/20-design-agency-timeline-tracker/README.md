## How to use

1. Open the Google Sheet and make a personal copy (File → Make a copy).
2. Fill in the **Projects** sheet with each client project; the Project ID can be any unique text.
3. Add tasks in **Deliverables**, linking each to its Project ID. Assign owners and due dates.
4. Team members log daily hours and notes in **Progress**; the Dashboard updates % Complete and total hours automatically.
5. If you track income or expenses, record them in the **Finance** sheet – the running balance updates automatically.
