## How to use

1. Purchase and download the zip file from Gumroad.
2. Open the Google Docs version in your browser or download the Word file to edit locally.
3. Replace placeholder text with your own information, keeping the provided headings and bullet format.
4. Save or export the finished resume as PDF for submission to employers.

## Notes

- This is a planning and organising tool for personal use. It does not give financial, medical, legal or career advice and does not promise any result.
- Sample rows and placeholder text are examples: replace them with your own.
