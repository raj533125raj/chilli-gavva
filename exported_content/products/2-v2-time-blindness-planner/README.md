## How to use

1. Print the A4 or US Letter file at 100% (actual size).
2. Print a fresh Today page every morning and tick your time anchors as you go.
3. Guess how long a task takes, then write the real time: it trains your sense of time.
4. Use the Weekly Overview on Sunday and the Monthly Review at the end of the month.
