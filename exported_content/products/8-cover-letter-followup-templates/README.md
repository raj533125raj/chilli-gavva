## How to use

1. Download the PDF files (or the Google Docs file) from the Gumroad receipt page.
2. Open each template in Microsoft Word or Google Docs and replace every bracketed placeholder (e.g., [Your Name], [Company]) with your own information.
3. Run the ATS checklist in the Customization Guide to confirm font, file name, and lack of images meet scanner requirements.
4. Export the edited cover letter as a PDF and attach it to your job application.
5. After submitting, copy the follow‑up email template, fill in the specifics, and send it within 5–7 business days.
