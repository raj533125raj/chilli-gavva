# Bundles

Each JSON file here is a bundle: ONE PDF made from the real pages of the products it names (`bundle_of`),
with one cover, one How to use page and one "What's inside" list. The Product Builder builds it into
`exported_content/products/bundle-<name>/` once per `revision` and runs the Truth Checker.
Nothing is marked for sale: the owner reads the listing text first and decides.
