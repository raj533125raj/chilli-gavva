# Product Bible Specs

This directory contains 10 verified, production-ready product specs that pass the Truth Checker (`truth_check.py`).

Each spec defines honest product metadata, listing descriptions, user instructions, and exact file contents. Listings make no promises beyond what the built files deliver.

## Specs List

1. `paycheck-budget-planner.json`: Printable PDF planner in A4 and US Letter (cover, How to use, Monthly Budget, Bills Table with Paid column, Savings, Notes) and an Excel (.xlsx) workbook with Ledger and Bills tabs.
2. `bills-debt-tracker.json`: Printable PDF planner (Debt List with name, type, balance, rate, and minimum payment; Payment Log; Monthly Bills) and an Excel (.xlsx) workbook with running balances.
3. `savings-goals-planner.json`: Printable PDF planner (Goals Table with target dates, Deposits Log, Savings Notes) and an Excel (.xlsx) workbook with Deposits tab.
4. `daily-habit-tracker.json`: Printable PDF planner featuring a 7-day habit grid with tick boxes and weekly review.
5. `monthly-habit-grid.json`: Printable PDF planner featuring a 31-day habit grid with tick boxes split across pages as handled by the builder.
6. `small-business-income-log.json`: Excel (.xlsx) workbook with Instructions and Income Log tab calculating separate In and Out totals.
7. `sales-inventory-sheet.json`: Excel (.xlsx) workbook with Instructions, Inventory, and Sales tabs.
8. `pricing-calculator.json`: Excel (.xlsx) workbook with Instructions, Calculator, and Materials tabs.
9. `monthly-money-summary.json`: Excel (.xlsx) workbook with Instructions, Monthly Summary, and Category Breakdown tabs.
10. `weekly-planner.json`: Printable PDF planner with Weekly Schedule, 7-day Habit Tracker grid, and Weekly Budget page.
