# Tenglish style guide — words the robot can send

Tenglish = Telugu sentence words in English letters + common English nouns kept English.

## Rule of thumb

- Sentence starts in Telugu words; only the thing itself stays English.
- If people say the word in English around the Office, keep it English.
- If a Telugu word exists and people use it, use the Telugu word, not a translated pure-Telugu noun.
- Keep messages short and one idea per line.
- No money amounts, no secrets, no push without the owner.

Tenglish: ee style chesi robot messages bayatisthayi, meeku kosam sare ga undi.

## English nouns we keep English

Office, Room, Brain, Agent, Draft, Task, Team, Pack, Upload, Pin, Post, Store, Listing, Tags, Cover, Preview, Settings, Dashboard, Button, Command, List, View, Approve, Reject, Pause, Resume, Help, Rules, Cubes, Doctor, Pipeline, Status, Today, Posted, Niche, Idea, Research, Council, Checker, Review, Score, Build, Product, File, Zip, Checklist, Plan, Schedule, Run, Cloud, Bot, Telegram, Phone, Message, Queue, Stuck, Retry, Fix, Ready, Needs Fix, Verdict, Truth, Proof, Auto, Warning, Error, OK, Failed.

Room nouns: Captain, Main agent, Worker, Face, Logo, Crown, Hat, Chip, Desk, Panel, Mirror, Left hand, Right hand, Theme, Language, Focus, Mute, Unmute, Undo, Rename, Move, Resize.

Product nouns: PDF, Excel, XLSX, Notion, ZIP, Cover, Thumbnail, Image, Page, Sheet, Worksheet, Row, Column, Checklist, License, README, Draft, Listing, Tags, Description, What you get, Price, Pack, Upload pack, Listing text, Product folder, File name.

Platform nouns: Pinterest, Instagram, Telegram, GitHub, Notion.

Money is never printed. Secrets are never printed: no tokens, keys, account ids, database paths, or private store file names.

## Bad examples — avoid these

1. "Pani gadi start avuthu" — wrong: "Pani gadi" is pure Telugu noun; use Task.
2. "Musayida bayata vachindi" — wrong: "Musayida" is pure Telugu noun; use Message.
3. "Medhassu okka undi" — wrong: "Medhassu" is pure Telugu noun; use Brain.
4. "Pani gadi cheptha mee task chestha" — wrong: "Pani gadi" again; use Task.
5. "Mee thodi office kosam pin post cheyandi" — wrong: "thodi" is not Tenglish token used here; use "Mee".
6. "Ee room meeku kosam leda mee team kosam" — wrong: room is ok but keep sentence simple: Mee room meeru kosam undi.
7. "Mee em chesthe mee task okay?" — wrong: too vague; say the action, e.g., Mee task approve cheyandi?
8. "Ee draft meeku thappa ayyindi" — wrong: "thappa" is not a Tenglish token here; use thappu or too generic.
9. "Mee upload pack kosam price set cheyandi" — wrong if you add a price amount; never print price.
10. "Mee pack upload cheyinchoku, price set cheyandi" — wrong: price with an amount is not allowed; only a no-amount reminder is ok.
11. "Mee listing kosam price 99 set cheyandi" — wrong: money amount is not allowed.
12. "Mee store kosam price [amount] set cheyandi" — wrong: money amount is not allowed.
13. "Mee draft kosam earnings [amount]" — wrong: money amount is not allowed.
14. "Mee real earnings [amount] this week" — wrong: money amount is not allowed.
15. "Token undi, bot start avuthu" — wrong: token mention is a secret danger; never show token.

Tenglish: ee bad examples ni avoid cheyandi.

## Quick checklist for the robot

- Sentence in Telugu words? yes.
- English nouns only the thing itself? yes.
- One idea per line? yes.
- No money amount? yes.
- No secret? yes.
- Short and clear? yes.

Tenglish: ee checklist pass ayithe message pampandi.
