# Owner Week Routine Guide (Tenglish House Style)

Chilli Gavva robot mee kosam 24/7 autonomous ga digital products scout chesthundi, drafts create chesthundi, mariyu ready upload packs build chesthundi.
Kani owner ga mee time chaala viluvainadi: meeru rojantha monitor cheyalsina avasaram ledu.
Ee simple schedule follow aithe saripothundi:
- **Daily 10 Minutes:** Phone nunchi Telegram lo decisions mariyu daily social posts.
- **Sunday 30 Minutes:** Weekly review, manual upload to stores, mariyu next week plan.

> **Crucial Rule:** Robot eppatiki automate ga sell cheyadu, post cheyadu, publish cheyadu leda customer ki email send cheyadu. Prices anni store lo owner matrame direct ga set chestharu. Zero money mentions rule strict ga enforce cheyabaddadi.

---

## 📅 Daily 10 Minutes Routine (Prati Roju Morning / Evening)

Prati roju 10 nimishalu mathrame mee phone lo Telegram open chesi ee 3 steps cheyandi:

### Step 1: Drafts Check & Quick Decisions (3 Minutes)
Robot scout chesina kotha draft ideas queue lo wait chesthuntayi.
1. `/list` ani Telegram lo pampandi (leda `/decide`).
2. Draft title, audience mariyu Checker score (0-100) chudandi.
3. Decison thesukondi:
   - Manchi idea & audience clear ga unte: `/approve <ID>` (leda `[✅ ID]` tap cheyandi).
   - Boring, generic leda weak niche anipisthe: `/reject <ID>` (leda `[❌ ID]` tap chesi reason select cheyandi).
4. Approve aina drafts ventane Product Builder queue loki velthayi. Next cycle lo automatic ga complete pack (PDFs, mockups, listing text) build avthundi.

### Step 2: Post Today Social Media (5 Minutes)
Robot prati roju morning social media post plan prepare chesthundi.
1. `/post today` ani Telegram lo pampandi.
2. Robot meeku ready assets pampisthundi:
   - Pinterest pin image + exact title + description + hashtags.
   - Instagram carousel slides leda reel frames + clean caption.
3. Mee phone nunchi Pinterest leda Instagram app open chesi copy-paste chesi publish cheyandi.
4. Post chesaka Telegram lo `/posted 1` ani pampandi. Robot post completed ani note chesukuntundi.

### Step 3: Robot Status Quick Scan (2 Minutes)
1. `/status` ani pampandi.
2. Health check ok na chudandi (AI provider quotas, build pipeline counts, 0 stuck items).
3. Emaina urgent doctor alert unte chusi `/doctor` tho check cheyandi. Anthe, mee daily routine complete!

## 🌟 Sunday 30 Minutes Routine (Aadivaram Weekly Routine)

Sunday roju Chilli Gavva robot weekly routine run chesthundi (marketing all, weekly newsletter draft, calendar export, ops report, changelog).
Owner ga meeru ee 30 minutes lo store update chesi weekly performance chusukondi:

### Step 1: Weekly Performance & Operations Review (5 Minutes)
1. `/week` ani Telegram lo pampandi:
   - Ee vaaram enni drafts vachayi, enni approve chesam, enni packs ready ayyayi chudandi.
2. `/ops` mariyu `/dup` check cheyandi:
   - Operations summary chusi system reliability verify cheyandi.
   - Duplicate checker report chusi content unique ga undani confirm chesukondi.
3. Optional ga `/dashboard` ani pampithe HTML dashboard document vasthundi.

### Step 2: Review Ready Upload Packs (10 Minutes)
1. `/packs` ani pampandi. Ee vaaram build aina ready upload packs list chudandi.
2. Prati pack details chudadaniki `/pack <ID>` pampandi.
3. Verification checks:
   - Truth check verdict: READY.
   - Deep QA verdict: PASS.
   - Listing lint: PASS (clean title, tags, description).
   - Pack files: `product.zip`, `cover.png`, `listing.txt` anni unnayani confirm cheyandi.

### Step 3: Manual Store Upload & Listing (10 Minutes)
1. Telegram nunchi pack files thesukondi:
   - `/files <ID>` — Main product zip, cover image mariyu listing text vasthayi.
   - `/covers <ID>` — Cover variants vasthayi.
   - `/launch <ID>` — Store launch checklist markdown vasthundi.
2. Mee Gumroad, Topmate leda Payhip store admin dashboard open cheyandi:
   - New Digital Product create cheyandi.
   - `listing.txt` nunchi Title, Description, Tags copy-paste cheyandi.
   - Deliverable file ga `product.zip` upload cheyandi.
   - Cover image ga `cover.png` upload cheyandi.
   - **Price:** Owner ga meeru nirdishtamaina price enter cheyandi.
   - Publish cheyandi.

### Step 4: Next Week Calendar & Ideas Review (5 Minutes)
1. `/calendar` ani pampithe vachina `post_plan.ics` calendar file chusi upcoming week posting plan check cheyandi.
2. `/ideas` pampinchi scout robot score chesina top upcoming ideas chudandi.
3. Emaina special niche focus kavali ante `/settings` lo niches tweak cheyandi.

## 🛡️ Operational Golden Rules for Owner

1. **Zero Auto-Posting:** Robot eppatiki direct ga external platforms lo post cheyadu. Meekue files isthundi; meeru okasari glance vesi phone nunchi post chestharu.
2. **Zero Auto-Selling:** Pricing, store accounts, bank links robot touch cheyadu. Meeru matrame store owner.
3. **Quiet Hours Respected:** Night 22:00 nunchi 08:00 IST varaku robot alerts pampadu. Emergency pause kavali ante `/pause` pampandi.
4. **Learning from Decisions:** Meeru reject chesinappudu reason select chesthe, robot aa mistakes malli repeat cheyakunda rules update chesukuntundi.
