# Two-week private, see the office validation plan

Goal: find out in 14 days whether ONE income stream gets real traction, before building more.
Budget: private, see the office. Only free tools (GitHub Pages, GitHub, free social/newsletter tiers).

## Pick the stream (decide first, write it down)
Hosting note: GitHub Pages forbids commercial sites, so use it only for this non-commercial test; host monetised pages on Cloudflare Pages.

Candidate: a free mini-tool page (e.g. a simple calculator or prompt generator) on GitHub Pages, with an email signup. Income later comes from honest affiliate links or a paid tier, but the test only measures interest.

## Success criteria (fixed before day 1)
- Visitors: at least 1,000 unique visitors in 14 days.
- Signups: at least 50 email signups.
- Engagement: at least 30% of visitors use the tool at least once.
- Real money: private, see the office required in this test. Any real earning must be recorded as `source = 'real'`.

If all three visitor/signup/engagement targets are met: continue with a second month of the same stream.
If not met: stop this stream, record the result in STATUS.md, pick the next candidate.

## Tracking (no paid tools)
- Visitors and clicks: GitHub Pages has no analytics, so add a free analytics snippet only if the user approves it (privacy note needed).
- Signups: count rows in the mailing list tool.
- Log daily numbers into agent_data.db as a `validation` row (source = 'real' for measured traffic, never for estimates).

## Rules
- No spam, no auto-posting to platforms that forbid bots.
- Every public page is reviewed by a human before publishing.
- Do not buy anything during the test.
- Write the result in STATUS.md on day 14, good or bad.
