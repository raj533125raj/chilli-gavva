# Chilli Gavva Owner Guide — Tenglish
> Simple commands for the owner in Telegram. Read this once, then use the robot.

## What this robot does
- This robot drafts small digital products and waits for you to say OK or not-OK.
- It never posts, sells or publishes anything without you.
- It never asks for money and never shows money without you first asking.

## Commands and examples
Use these in the Telegram chat with the bot. You can type in English or Tenglish. Tenglish means Telugu words written in English letters. Example: `help` or `sahaayam`.

### /help
- Tells you the commands again.
- English: `/help`
- Tenglish: `help` or `sahaayam`

### /list or /status
- `/list` shows drafts waiting for you to decide.
- `/status` shows a short health update: AI providers, drafts today, products, last run time.
- English: `/list`
- Tenglish: `drafts chupinchu` or `list chey`

### /view ID
- Read one draft fully. Use the number shown in `/list`.
- English: `/view 5`
- Tenglish: `draft 5 chupinchu` or `view 5`

### /approve ID
- Say OK to a draft. You can approve more than one at a time.
- English: `/approve 5` or `/approve 5 6`
- Tenglish: `draft 5 ni approve chey` or `5 aamodinchu`

### /reject ID
- Say not-OK to a draft. You can add a reason like `too generic` or `weak niche`.
- English: `/reject 5`
- Tenglish: `5 vaddu` or `draft 5 reject chey, too generic`

### /packs and /pack ID
- `/packs` lists upload packs ready for the store.
- `/pack ID` shows the plain listing text for one pack.
- English: `/packs`
- Tenglish: `packs chupinchu`
- English: `/pack 3`
- Tenglish: `pack 3 chupinchu`

### /pause and /resume
- `/pause` stops all AI work and new drafts. The bot still answers you in Telegram.
- `/resume` starts work again.
- English: `/pause`
- Tenglish: `anni pause chey` or `mottam aapu`
- English: `/resume`
- Tenglish: `resume chey` or `anni start chey`

## What the robot never does without you
- It never publishes, posts or sells anything automatically.
- It never sends money or asks you for money.
- It never changes a draft after you approve it, unless you ask.

## What "needs fix" means
- Sometimes a draft needs more work before it is ready.
- If you see "needs fix", the robot is asking you to send it back for another pass.
- You can /reject it with a reason, then the robot tries again.

## Quick notes
- The bot answers commands on its next run, about every 30 minutes. Not instantly.
- Buttons (Approve / Reject / View) work the same as typing the commands.
- After you reject, pick a reason so the robot learns.
- If you type something the robot does not understand, it will say "unknown" and suggest /help. That means try again with a simpler command.
